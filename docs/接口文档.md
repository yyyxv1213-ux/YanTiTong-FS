# 研题通·考研408刷题训练系统 — 接口文档

> 本文档依据后端源码（`com.ytt.modules` 下全部控制器、`com.ytt.common` 公共包与各 DTO 校验注解）整理，共收录 **41** 个接口。在线可视化文档见 `http://localhost:8080/api/swagger-ui.html`。
>
> **题库隔离约定（V4）**：刷题、组卷、统计、后台题目/分类等接口均支持 `bankCode` 参数（题库编码，如 `ky408`）；学员端不传时后端归一化为默认题库 `ky408`，传入不存在或未上线的题库返回 `40000`。题库列表与科目定义由 `GET /common/banks` 下发。

## 1. 通用约定

### 1.1 Base URL

```
http://localhost:8080/api
```

所有接口路径均以 `/api`（context-path）为前缀，下表路径均省略该前缀。

### 1.2 认证方式

除公开接口外，所有请求需携带 JWT 访问令牌：

```
Authorization: Bearer {accessToken}
```

- 令牌通过 `/auth/login`、`/auth/register`、`/auth/refresh`、`/auth/email/login` 获取。
- `accessToken` 有效期 2 小时（7200 秒），`refreshToken` 有效期 7 天（604800 秒）。
- 注销（`/auth/logout`）或修改密码后，原 accessToken 进入黑名单，再次使用返回 `40103`。

### 1.3 统一响应体

所有接口返回统一结构，**HTTP 状态恒为 200**，业务结果以 `code` 判断：

```json
{
  "code": 0,
  "message": "操作成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | `0` 表示成功；非 0 为错误码（见第 2 节） |
| message | string | 结果描述；参数校验失败时给出字段级提示 |
| data | object/array/null | 业务数据，失败时为 `null` |

### 1.4 分页约定

- 请求参数：`pageNum`（页码，从 1 开始，默认 1）、`pageSize`（每页条数，默认 10，最大 100）。
- 响应 `data` 为 `PageResult`：

```json
{
  "records": [],
  "total": 100,
  "current": 1,
  "size": 10
}
```

### 1.5 参数校验

请求体参数通过 JSR-303（`@Validated`）校验。校验失败返回 `code=40000`，并在 `message` 中给出字段级提示（如"用户名不能为空""难度范围为 1-3"）。Query 参数缺失/类型不匹配分别返回 `40001`/`40002`。

### 1.6 接口限流

按客户端连接 IP 限流（取请求的远程地址 `getRemoteAddr()`，不信任可伪造的 `X-Forwarded-For` 头，见 `RateLimitAspect`），超限返回 `42900`：

| 接口 | 限额 |
| --- | --- |
| `POST /auth/login` | 5 次/分钟 |
| `POST /auth/register` | 10 次/分钟 |
| `POST /auth/email/code` | 10 次/分钟 |
| 其余接口 | 默认 120 次/分钟（`rate-limit.default` 配置） |

此外，邮箱验证码设有**业务级防刷**：同一邮箱两次发送间隔不得短于 60 秒，否则返回 `42901`（不受接口限流影响）。

## 2. 错误码表

| code | 含义 | 说明 |
| --- | --- | --- |
| 0 | 操作成功 | 业务处理成功 |
| 40000 | 请求参数错误 | JSR-303 校验失败，message 含字段级提示 |
| 40001 | 缺少必要参数 | 必填 Query 参数缺失 |
| 40002 | 参数类型不匹配 | 参数类型无法转换 |
| 40100 | 未登录或登录已过期 | 未携带或无法解析有效 Token |
| 40101 | Token 无效 | Token 签名校验失败或格式错误 |
| 40102 | Token 已过期 | Token 超出有效期，需刷新或重新登录 |
| 40103 | Token 已被注销 | Token 在注销黑名单中（注销/改密后） |
| 40104 | 用户名或密码错误 | 登录凭证校验失败 |
| 40105 | 账号已被禁用，请联系管理员 | 账号 status=0 |
| 40106 | 邮箱验证码错误 | 验证码与邮箱不匹配 |
| 40107 | 验证码已过期，请重新获取 | 验证码未发送、已过期或已被一次性消费 |
| 40300 | 无权限访问该资源 | 已登录但无访问权限 |
| 40301 | 当前角色无权执行该操作 | 角色校验未通过（如非 ADMIN 访问管理端） |
| 40400 | 请求的资源不存在 | 通用资源不存在 |
| 40401 | 用户不存在 | 指定用户 ID 不存在 |
| 40402 | 题目不存在 | 指定题目 ID 不存在 |
| 40403 | 分类不存在 | 指定分类 ID 不存在 |
| 40404 | 记录不存在 | 考试/作答等记录不存在 |
| 40901 | 用户名已被占用 | 注册/新增/编辑用户时用户名冲突 |
| 40902 | 数据已被他人修改，请刷新后重试 | 乐观锁冲突 |
| 40903 | 不能禁用当前登录的管理员账号 | 禁用自身保护 |
| 40904 | 不能删除内置管理员账号 | 内置 `admin` 账号删除保护 |
| 40905 | 邮箱已被注册 | 注册/新增/编辑用户时邮箱冲突 |
| 42900 | 请求过于频繁，请稍后再试 | 触发接口限流 |
| 42901 | 验证码发送过于频繁 | 同一邮箱 60 秒内重复获取验证码 |
| 50000 | 系统内部错误 | 未捕获的服务端异常 |
| 50001 | 数据库操作失败 | 持久层异常 |
| 50002 | 邮件发送失败 | SMTP 服务异常或网络故障，请稍后重试 |

## 3. 接口分组明细

权限标识：**公开**（无需登录）、**登录**（任意已登录用户）、**ADMIN**（需 ADMIN 角色）。

### 3.1 认证模块 `/auth`

| 方法 | 路径 | 权限 | 说明 | 关键请求参数 | 响应 data 概要 |
| --- | --- | --- | --- | --- | --- |
| POST | /auth/login | 公开 | 用户登录（限流 5 次/分钟/IP） | Body：`username` 必填、最长 64；`password` 必填、6-32 位（用户不存在返回 `40401`，密码错误返回 `40104`） | `TokenResponse`：`accessToken`、`refreshToken`、`expiresIn`（秒）、`user{id,username,email,realName,roles}` |
| POST | /auth/register | 公开 | 用户注册（限流 10 次/分钟/IP），注册即登录 | Body：`username` 必填、3-20 位字母/数字/下划线；`email` 必填、合法邮箱格式、最长 128（库内唯一，重复返回 40905）；`password` 必填、6-32 位；`confirmPassword` 必填（需与密码一致）；`realName` 可选、最长 30 | 同上 `TokenResponse`（学员角色） |
| POST | /auth/email/code | 公开 | 发送邮箱登录验证码（限流 10 次/分钟/IP，同一邮箱 60 秒防刷返回 42901） | Body：`email` 必填、合法邮箱格式；邮箱未注册返回 `40401`，账号被禁用返回 `40105` | `null`（向该邮箱发送 6 位数字验证码，5 分钟内有效） |
| POST | /auth/email/login | 公开 | 邮箱验证码登录（免密码登录通道，凭"邮箱+验证码"换取 Token） | Body：`email` 必填、合法邮箱格式；`code` 必填、6 位数字（错误返回 `40106`，过期/未发送/已消费返回 `40107`，邮箱未注册返回 `40401`） | 同登录 `TokenResponse`；校验成功后验证码立即失效（一次性消费） |
| POST | /auth/refresh | 公开 | 刷新令牌 | Body：`refreshToken` 必填 | 同上 `TokenResponse` |
| POST | /auth/logout | 登录 | 注销登录，当前 accessToken 加入黑名单 | Header 携带 Token 即可，无请求体 | `null` |

### 3.2 管理端-用户管理 `/admin/users`

整组接口需 **ADMIN** 角色（`SecurityConfig` 路径规则 + `@PreAuthorize` 双重控制）。

| 方法 | 路径 | 权限 | 说明 | 关键请求参数 | 响应 data 概要 |
| --- | --- | --- | --- | --- | --- |
| GET | /admin/users | ADMIN | 用户分页列表 | Query：`keyword`（用户名/姓名模糊）、`status`（1 启用/0 禁用）、`pageNum`、`pageSize` | `PageResult<SysUser>` 用户分页 |
| GET | /admin/users/{id} | ADMIN | 用户详情 | 路径：`id` | `SysUser` 用户实体 |
| GET | /admin/users/roles | ADMIN | 角色列表 | 无 | `List<SysRole>` 全部角色 |
| POST | /admin/users | ADMIN | 新增用户 | Body：`username` 必填、4-20 位字母/数字/下划线；`email` 必填、合法邮箱格式（库内唯一，重复返回 40905）；`realName` 最长 20；`password` 新增必填、6-20 位；`status` 必填（0/1）；`roleCodes` 至少 1 个角色编码 | `null` |
| PUT | /admin/users/{id} | ADMIN | 编辑用户 | 路径：`id`；Body 同新增（`password` 留空表示不修改；更换邮箱需通过唯一校验） | `null` |
| PUT | /admin/users/{id}/status | ADMIN | 启用/禁用用户 | 路径：`id`；Body：`status` 必填、只能 0 或 1（禁用自身返回 40903） | `null` |
| PUT | /admin/users/{id}/password | ADMIN | 重置用户密码 | 路径：`id`；Body：`password` 必填、6-20 位 | `null` |
| PUT | /admin/users/{id}/roles | ADMIN | 分配用户角色 | 路径：`id`；Body：`roleCodes` 至少 1 个角色编码 | `null` |
| DELETE | /admin/users/{id} | ADMIN | 删除用户 | 路径：`id`（内置 `admin` 返回 40904） | `null` |
