# 研题通·用户操作手册

> 文档版本：v1.0

> 适用版本：v1.0（题库 120 题版本）
> 说明：本手册为文字版操作说明，界面截图将在部署到固定演示环境后补录，当前不随文档附带图片。

## 1. 系统简介

研题通是一个面向考研 408 的在线刷题训练系统，包含学员端与管理端。学员用它抽题训练、模拟考试、管理错题、查看学习统计；管理员通过浏览器维护题目、分类和用户账号。系统前后端分离，浏览器访问前端页面即可完成全部操作，无需安装客户端。

## 2. 准备与登录

### 2.1 访问系统

- 浏览器打开管理员提供的前端地址（本地开发环境为 `http://localhost:5173`）
- 推荐 Chrome / Edge / Firefox 桌面端最新版本；系统按桌面宽度设计，暂不建议手机直接访问

### 2.2 登录方式

登录页提供两个选项卡：

1. **密码登录**：输入用户名和密码，点击登录。用户名是唯一标识（不是邮箱）。
2. **验证码登录**：切换到「验证码登录」选项卡，输入邮箱，点击发送验证码，6 位数字码 5 分钟内有效，填入后登录。若后端未配置发信邮箱，发送验证码会提示失败（错误码 50002），此时请改用密码登录。

内置演示账号：管理员 `admin / 123456`，学员 `study / 123456`（首次登录后请尽快在个人中心改密）。

### 2.3 注册新账号

登录页点击「注册」，填写用户名、邮箱、密码与确认密码，可选填真实姓名。注册成功后自动登录进入学员端。用户名或邮箱与现有账号重复时会给出对应提示。

### 2.4 退出与登录态

- 页面右上角可退出登录；登录态失效（Token 过期且无法刷新）时，系统会自动跳回登录页
- 修改密码成功后会强制退出，需要用新密码重新登录

## 3. 学员端操作

### 3.1 题库切换

页面顶栏有题库大类下拉框（当前上线「考研408·计算机学科专业基础」）。切换后，刷题、模拟考试、统计口径都会跟随当前题库；选择会记住，下次打开无需重选。

### 3.2 仪表盘

登录后首屏即为仪表盘，从上到下依次是：

- **学习总览卡片**：今日刷题数 / 累计刷题数 / 累计正确率 / 每日目标 / 距考试天数倒计时，并给出今日进度百分比
- **分科统计**：四科各自的题量与正确率
- **近 14 天趋势**：每日刷题数与答对数的折线图，没刷题的日期按 0 计

### 3.3 刷题训练

1. 进入「刷题训练」页，设置筛选条件：科目、章节、题型（单选/多选/判断）、难度（易/中/难）、模式（顺序 / 随机 / 错题）、每次抽题数量（默认 10，最多 50）
2. 点击开始抽题，逐题作答：单选/多选点选选项，多选可多次点选与取消
3. 点击「提交」即时判分：页面显示对错、正确答案与解析
4. 答错的题目自动进入错题本；答对且此前在错题本中的题目会被标记已掌握
5. 用「上一题 / 下一题」在本次抽到的题目间切换，已作答的题目可回头查看判定结果

### 3.4 模拟考试

1. 进入「模拟考试」页，设置题量（5-100，默认 20）与时长（5-180 分钟，默认 30），可限定科目，点击「开始考试」
2. 考试中页面右上角显示倒计时；题目支持标记作答状态，可来回跳转修改
3. 点击「交卷」弹出确认框；若还有未作答的题目，确认框会提示剩余数量
4. 交卷后立即显示成绩：得分、答对数、总题数。超过时限（含 5 分钟网络宽限）再交卷，系统提示成绩无效
5. 在「考试历史」中查看以往考试列表；点击某次考试可打开成绩报告，逐题对照自己的作答与正确答案、解析

### 3.5 错题本

- 列表按最近出错时间倒序展示未掌握的错题，附错误次数
- 点击某题可在线重做，判分后显示答案解析
- 确认已掌握的题目点击「标记已掌握」，确认后从列表移除（记录保留，重错会再次归集）

### 3.6 学习统计

独立统计页提供比仪表盘更细的分科正确率与 14 天趋势数据，口径与当前题库一致。

### 3.7 学习计划

在「学习计划」页设置两项内容并保存：

- **每日目标题数**：默认 30，作为仪表盘今日进度的分母
- **考试日期**：默认 2026-12-19，作为倒计时依据

### 3.8 个人中心

- **修改姓名**：输入新的真实姓名保存，顶栏昵称随之更新
- **修改密码**：输入原密码、新密码与确认密码；两次输入不一致或原密码错误会提示，修改成功后自动退出重新登录

## 4. 管理端操作

使用 ADMIN 角色账号（如 `admin`）登录后，顶栏出现管理入口。

### 4.1 题目管理

1. 先在页面顶部选择题库与科目，列表按条件分页展示
2. 支持按关键字、分类、题型、难度组合筛选
3. 点击「新增」录入题目：填写题干、选项（2-4 个）、勾选正确答案、选择分类/题型/难度、填写解析；编辑与删除同理，删除前有确认提示
4. 题目一经发布即可被学员抽到，录入时请确认答案下标与选项文字对应无误

### 4.2 分类管理

- 按题库选择、科目标签页切换，维护章节分类
- 新增/编辑/删除；已被题目引用的分类无法删除，后端会说明原因

### 4.3 用户管理

- 分页查询全部用户，可编辑用户资料、邮箱、启用/禁用状态与角色
- 「重置密码」为用户设置新密码；禁用后的账号无法登录
- 角色决定权限：STUDENT 仅学员端，ADMIN 可访问管理端

## 5. 常见问题

| 现象 | 原因与处理 |
|------|------------|
| 提示「请求过于频繁」（42900） | 触发了接口限流（如登录 5 次/分钟），等待一分钟后重试 |
| 发送验证码报错（50002） | 服务器未配置发信邮箱，请改用密码登录 |
| 提示「用户名或密码错误」 | 核对用户名拼写（用户名不是邮箱）；忘记密码联系管理员重置 |
| 交卷提示「考试已超时，成绩无效」 | 超过考试时限（含 5 分钟宽限），本次考试作废，请重新组卷 |
| 刷新页面后被登出 | 登录态已过期且无法续期，属于正常安全策略，重新登录即可 |
| 统计图表为空 | 当前题库下暂无作答记录，先去刷几题再回来看 |
