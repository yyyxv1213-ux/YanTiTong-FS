## 1. 引言

### 1.1 编写目的
这个项目由我一个人完成开发和自测，缺不了正规团队的交叉评审，所以更要把测试过程落成文字：哪些功能我验证过、用什么办法验证的、结果如何，都记录在案。本文档就是这轮自测的安排说明，测试结论见配套的《测试报告》。

### 1.2 项目背景
研题通是一款面向研究生入学考试（408 计算机学科专业基础）的在线刷题平台，采用前后端分离架构：
- **后端**：Spring Boot 2.7.18 + MyBatis-Plus + Spring Security + JWT + Flyway + MySQL 5.7
- **前端**：Vue 3.4 + Vite 4.5 + Element Plus 2.7 + Pinia + TypeScript

### 1.3 参考文档
- 《产品需求文档 v1.0》（本仓库 docs 目录，与测试同期整理成文）
- 《接口文档》（docs/接口文档.md，含统一响应结构与错误码）
- 《数据库设计》（docs/数据库设计.md，对应 V1~V4 迁移脚本）
- 《部署文档》（docs/部署文档.md）

## 2. 测试范围

### 2.1 功能范围（In-Scope）
| 模块 | 核心功能点 | 优先级 |
|------|-----------|--------|
| A 认证模块 | 注册/登录/双 Token 刷新/邮箱验证码/注销/改密 | P0 |
| B 公共接口 | 题库列表、科目元数据 | P1 |
| C 刷题训练 | 抽题（默认/条件/随机）、判分、错题记录 | P0 |
| D 模拟考试 | 组卷、防重放交卷、历史、成绩报告、越权控制 | P0 |
| E 错题本 | 错题列表、标记掌握 | P1 |
| F 统计/计划/个人中心 | 学习统计、学习计划、资料修改、密码修改 | P1 |
| G 管理端 | 题目 CRUD、用户管理、分类管理 | P0 |
| H 越权与注入 | RBAC 越权、SQL 注入、XSS 存储、非法请求 | P0 |
| I 限流 | 接口限流、XFF 防伪 | P1 |

### 2.2 非功能范围
- **兼容性**：Chrome / Firefox / Safari / Edge 主流浏览器；PC 端 / 移动端
- **性能**：接口响应时间、并发处理能力、JVM 资源占用
- **安全**：SQL 注入、XSS、CSRF、权限控制、Token 安全、限流绕过
- **可靠性**：Token 轮换、黑名单、异常恢复

### 2.3 不在范围内（Out-of-Scope）
- 第三方支付/短信网关（当前未接入）
- 集群部署下的分布式会话（当前为单体内存实现）
- 生产环境压测（仅开发环境基准测试）

## 4. 测试策略与方法

### 4.1 功能测试
- **后端单元测试**：JUnit + Spring Boot Test + H2 内存库，覆盖 Service/Controller 层
- **接口自动化测试**：Node.js 零依赖脚本，覆盖 9 大模块 64 个用例
- **前端单元测试**：Vitest + jsdom，覆盖工具函数与状态管理
- **手工探索性测试**：关键业务流程走查（注册→刷题→考试→错题→统计）

### 4.2 兼容性测试
- **代码静态分析**：检查 CSS 媒体查询、构建目标、Polyfill 配置
- **构建产物分析**：检查 chunk 大小、模块兼容性警告
- **理论矩阵评估**：基于 Element Plus 2.7 + Vue 3.4 官方支持矩阵推导

### 4.3 性能测试
- **基准测试**：单接口 avg/p50/p95/p99
- **并发测试**：1/10/25/50 并发阶梯加压
- **资源监控**：压测前后 JVM 内存占用采集
- **吞吐评估**：RPS 与错误率

### 4.4 安全测试
- **静态审计**：源码审查 SQL 拼接、XSS 渲染、权限注解、密钥管理
- **动态探测**：SQL 注入载荷、XSS 载荷、越权访问、Token 伪造/重放
- **限流验证**：同 IP 高频请求、X-Forwarded-For 伪造绕过

### 4.5 回归测试
- 每次功能开发或缺陷修复后，全量执行：
  - 后端 `mvnw test`（63 例）
  - 前端 `npm test`（14 例）
  - API 自动化 `node tools/api-test/api-test.mjs`（64 例）
